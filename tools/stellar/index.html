Character select layout

Drag a fighter into any cell. Empty cells stay empty in the game. Select slots with their checkboxes to remove them from this roster.

Import source projects

Choose a character folder, a stellar_project.json, or a parent Characters directory to import multiple fighters.

Existing packages are updated by name. Each project uses its original model, portrait, and audio files. Blender converts the model for Sagas.

Imported packages

Removing a roster slot keeps its package and source assets. You can add it back without converting it again.

Character project

Open an imported character to edit its source project.

Bone mapping, animation clips, hitboxes, physics, sounds, stages, and input bindings are stored in the source project.

Game scene edition

Edit descriptor tables that drive CSS, menus, title, HUD, and HD slots. Paths are asset-relative; no sprite directories are hardcoded in the scenes.

HD fighter models

Import an FBX such as HD/Mia.fbx. Stellar converts it, writes hd_models.tsv, and character select includes it on the FFA grid.
